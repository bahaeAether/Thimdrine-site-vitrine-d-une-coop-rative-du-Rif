# Thimdrine — Coopérative du Rif

Site vitrine de la coopérative Thimdrine, qui réunit 25 femmes de la région de Nador autour du miel de thym, de l'huile d'olive et de la confiture de figue de barbarie.

## Pages

- Accueil : présentation, produits phares et accès à la demande de commande.
- Nos produits : les six formats proposés et leurs prix.
- À propos : histoire, valeurs et chiffres clés de la coopérative.
- Contact : formulaire de demande de commande avec validation HTML native.

## Technologies

HTML5 sémantique et CSS3 natif (Flexbox, variables CSS et mises en page adaptatives). Le site ne nécessite ni framework ni JavaScript.

## Lancer le site

Ouvrir `docs/index.html` dans un navigateur ou servir le dossier du dépôt avec un serveur statique. Les pages sont dans `docs/`, prêtes à être publiées sur GitHub Pages en choisissant le dossier `/docs` comme source.

## Formulaire

Le formulaire utilise les contrôles natifs du navigateur pour valider les champs. La réception effective des demandes nécessite de connecter le formulaire à une adresse ou à un service de traitement avant le déploiement.
